# MVP v1 范围与行为契约

## 1. 本版目标

匿名用户可以输入一句问题、学习主题或任意长度纯文本，选择配置，获得有证据的题目，完成逐题作答并查看本次报告。

```text
输入与配置
  → 后端识别输入类型并执行安全检查
  → 解析用户原文或检索官方资料
  → 生成并校验 5/10 道题
  → 逐题作答并查看解析与证据
  → 程序判分并生成本次报告
```

## 2. 首版包含

| 领域 | 冻结范围 |
|---|---|
| 用户 | 匿名使用，不登录 |
| 输入 | 问题、主题、纯文本、问题与原文混合输入 |
| 配置 | 5/10 题；基础/进阶；单选/判断 |
| 来源 | 用户原文、阿里云百炼联网搜索返回的候选来源、受控网页正文抓取 |
| 出题 | 知识点规划、结构化题目、唯一答案、解析、来源和证据 |
| 答题 | 逐题选择、提交后锁定、即时结果、查看依据 |
| 报告 | 题数、正确数、正确率、用时、知识点表现、错因和下一步建议 |
| 状态 | 空输入、敏感信息、内容不允许、来源不足、抓取失败、限流、超时、会话过期、网络失败 |
| 数据 | 后端进程内会话 60 分钟；前端本地缓存 24 小时 |

| 动态补题、自适应追题、连续答对通关 | 后续阶段 |
| 历史记录、复习中心、长期画像 | 后续阶段 |

## 4. 页面与原型映射

实现仍使用现有 Uni-app 工程，不重新创建框架。

| Uni-app 页面 | 采用的原型 | 包含状态 |
|---|---|---|
| `pages/index/index` | 核心原型 01、02；系统状态 29、30、33 | 快速开始、输入配置、空输入、敏感信息、来源不足 |
| `pages/generating/index` | 核心原型 04；系统状态 31、32 | 真实等待、超时、断网重试 |
| `pages/quiz/index` | 核心原型 06、07 | 题目、提交后锁定、答对/答错、证据来源 |
| `pages/report/index` | 核心原型 09；系统状态 36 | 本次报告、会话过期、按原设置重新生成 |

明确不实现核心原型 03、05、08，也不实现学习复盘、分享创作和订阅提醒页面。

## 5. 输入行为

1. 前端不显示字数计数，不设置“有效字数”类的最少/最多学习门槛；只检查去除空白后是否为空。
2. 用户输入“RAG 是什么？”这类一句话问题可以直接生成题目。
3. 只有去除首尾空白后为空，前端才直接阻止提交。
4. API 的 `learning_input.text` 没有 `maxLength`；超长内容由后端分块处理。
5. 网关可以设置防滥用请求体上限，但不能把它描述为学习内容字数限制。
6. 后端识别 `QUESTION`、`USER_SOURCE` 或 `HYBRID`，不依赖字符数量判定。
7. 输入发现身份证号、密码、密钥或未授权商业机密时，不回显敏感内容，只返回可操作的错误。

## 6. 来源行为

### QUESTION

- 强制检索公开来源。
- 优先政府、标准组织、大学、论文发布机构和产品官方文档。
- 首选阿里云百炼内置联网搜索获取候选来源，再由受控抓取器读取正文；不允许把搜索摘要直接冒充原文证据。
- 找不到可核验来源时不出题，返回 `RELIABLE_SOURCE_NOT_FOUND`。

### USER_SOURCE

- 用户原文是主要证据。
- 可以使用官方资料补足必要背景，但必须以独立来源标注。
- 不允许模型常识代替证据。

### HYBRID

- 同时保留用户目标与用户原文。
- 题目证据可以来自用户原文或官方补充来源。
- 每条证据都必须能反查到唯一 `source_id`。

## 7. 生成与质量行为

1. 创建接口首版采用同步响应，成功返回 `201 READY`。
2. 前端生成页只显示不确定等待状态和真实已知信息，不显示伪造百分比或虚构阶段完成情况。
3. 每题必须通过 Schema、唯一答案、重复题、证据支持和内容安全检查。
4. 每题至少有一个直接证据片段；官方来源必须包含标题、发布方、URL 和抓取时间。
5. 单选题固定 4 个选项；判断题固定 2 个选项。
6. 题目可以随创建响应下发答案与解析，但前端在用户提交当前题前不得展示。
7. 首版不承诺防作弊，不把答案隐藏当成安全边界。

## 8. 作答与报告行为

1. 未选择答案不能提交当前题。
2. 当前题提交后答案锁定，展示对错、解析和证据。
3. 所有题完成后，一次向后端提交完整 `attempts`。
4. 后端验证题目是否完整、是否重复、答案选项是否合法。
5. 总题数、正确数、正确率、总用时和知识点统计全部由程序计算。
6. AI 只生成错因解释和行动建议；AI 报告失败时仍返回确定性的基础报告。
7. 相同会话、相同作答的重复提交返回同一报告；完成后提交不同作答返回 `RUN_ALREADY_COMPLETED`。

## 9. 状态流转

```text
POST /quiz-runs 成功
  → READY
  → POST /quiz-runs/{id}/submit
  → COMPLETED

READY 超过 60 分钟
  → GET/submit 返回 RUN_EXPIRED
```

同步生成期间的失败直接通过统一错误协议返回，不创建可恢复的半成品会话。

## 10. 错误码与前端动作

| 错误码 | HTTP | 前端动作 |
|---|---:|---|
| `EMPTY_INPUT` | 422 | 聚焦输入框，不丢失当前内容 |
| `SENSITIVE_INFORMATION` | 422 | 保留输入并提示删除敏感信息 |
| `CONTENT_NOT_ALLOWED` | 422 | 保留输入并提示修改内容 |
| `RELIABLE_SOURCE_NOT_FOUND` | 422 | 返回输入页，建议具体化问题或粘贴原文 |
| `SOURCE_FETCH_FAILED` | 502 | 允许重试；有用户原文时可按原文重新生成 |
| `RATE_LIMITED` | 429 | 结束加载，提示稍后重试 |
| `AI_TIMEOUT` | 504 | 保留输入和配置，允许有限重试 |
| `AI_OUTPUT_INVALID` | 502 | 保留输入和配置，允许重试或减少题量 |
| `INVALID_ATTEMPTS` | 422 | 留在答题页并定位未完成题目 |
| `RUN_NOT_FOUND` | 404 | 使用本地输入重新生成 |
| `RUN_EXPIRED` | 410 | 展示会话过期状态并按原设置重新生成 |
| `RUN_ALREADY_COMPLETED` | 409 | 展示首次报告，不覆盖旧作答 |
| `INTERNAL_ERROR` | 500 | 结束加载并展示 `request_id` |

## 11. 安全与隐私边界

- 百炼 API Key 仅存在后端环境变量中。
- 日志不记录完整输入、完整抓取正文、Authorization 或 API Key。
- 外部 URL 仅允许 HTTP/HTTPS，必须阻止本机、私网、链路本地、元数据地址和重定向绕过。
- 抓取正文是非可信数据，只能作为证据，不能改变系统指令或调用工具。
- 前端只缓存来源摘要和题目证据，不缓存完整外部页面。
- `/ready` 只检查配置是否存在，不发起收费请求。

| 项目 | 冻结值 |
|---|---:|
| 原文模式总超时 | 45 秒 |
| 联网检索模式总超时 | 75 秒 |
| 网络重试 | 最多 2 次 |
| 题目修复 | 最多 2 轮 |
| 生成模型调用预算 | 最多 4 次 |
| 报告模型调用预算 | 最多 2 次 |
| 后端会话 TTL | 60 分钟 |
| 前端缓存 TTL | 24 小时 |
| 官方来源候选目标 | 2–5 个 |

这些数值只有在压测或真实模型验证后才能通过新契约版本调整。
