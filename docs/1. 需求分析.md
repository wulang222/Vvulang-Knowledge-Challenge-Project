# 1. 需求分析:

## 1.1 需求分析

目标: 通过闯关得模式帮组用户学习枯燥的知识,巩固所学的内容

背景: 学习知识过于枯燥, 阅读繁杂的文档过于无聊,抓不住重点, 也不清楚自己到底实惠了还是不会, 尤其是在大学期间期末周老师发的复习资料又臭又长,  **不知道从哪开始复习,  通过实现一个这样的出题闯关学习的小程序能够帮组大家更 "轻松" "及时" 复习巩固一些知识内容**.

选择WX小程序原因: 随时随地的使用,符合"及时"学习的背景需求, 维系生态流量大,

免安装+方便推广和分享,朋友之间可以分享知识闯关成绩.

而且本项目可以实现垂直扩展, 例如(驾校宝典 面试题库 一些企业内部的知识培训)

## 1.2 人工需求分析

核心功能:

1. 用户可以自由输入一个他想学的知识(可以是一句话, 一个文段, 一段内容,一个视频,网页内容)

2. AI 自动从用户提供的资料或可核验的官方来源中获取知识并生成题目
3. AI自动交互式问答闯关的题目,选项,答案,通过提问闯关得形式来增加学习的趣味性
4. 用户可以自由答题闯关,选完题目后自动做出判断给出简析和正确答案, 无论答对答错
5. 通关后生成一个知识总结和复盘报告卡片. 用户可以分享给好友
6. 用户可以在后台分析自己所学的知识和答题情况,便于日后复盘,还可以生成报告

扩展功能(后续再做):

1. 运行输入知识库来生成题目(RAG技术): 可以

   用于企业培训,特定题库准备,考试复习

2. AI生图,可以根据知识的类型决定是否生成图片, 类似百词斩那种 根据图片来记单词

3. 充值VIP开启更多功能

4. 多人知识闯关在线对战, 排行榜, 语音读题
